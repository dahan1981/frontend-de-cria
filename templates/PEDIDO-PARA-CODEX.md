# Pedido para o Codex

Use o **Frontend de Cria** para redesenhar este projeto.

Leia primeiro o `AGENTS.md` deste projeto e a skill `frontend-de-cria` disponível no workspace.

## Objetivo

Quero que você analise o produto existente e **implemente o redesign diretamente no repositório**. Não quero apenas recomendações, wireframe, mockup ou um prompt para outro agente.

## Regras

- Preserve backend, APIs, autenticação, autorização, banco e regras de negócio.
- Preserve os fluxos funcionais atuais.
- Trate o frontend existente como referência funcional, não como obrigação estética.
- Defina uma direção visual coerente com o tipo de produto e usuário.
- Crie/refine tokens e componentes compartilhados para evitar patches inconsistentes.
- Melhore layout, navegação, typography, spacing, forms, tables, feedback, estados e responsividade quando necessário.
- Evite estética genérica de IA.
- Não invente funcionalidades nem dados.
- Rode checks técnicos disponíveis.
- Execute a aplicação e valide as principais telas no navegador.
- Verifique desktop e mobile.
- Faça pelo menos uma rodada de refinamento depois do primeiro render.

Ao final, me dê apenas um resumo objetivo do que mudou, do que foi preservado e do que foi verificado.
